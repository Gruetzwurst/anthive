# D1.2 – Speicherauslöser, Backups und Tab-Schutz

> Ausführung: superpowers:executing-plans, bestehender Feature-Checkout.

**Spec:** ../../2026-10-28-D1.0-DATENINVENTAR-UND-SPEICHERVERTRAG.md
**Ziel:** Manuelles Speichern, 5 aktive Echtzeitminuten Autosave,
15/60/180-Minuten-Backups und ein Schreiber pro Kolonie.
**Architektur:** Controller erfasst aktive Zeit, serialisiert Save-Aufträge;
IndexedDB schreibt Hauptstand/gewählten Backupslot atomar. Web Locks hält
exklusives Schreibrecht. UI ergänzt den vorhandenen HUD um Speichern/Status.

## Grenzen / technische Entscheidungen

Kein Menü oder Restore-/Importdialog (D1.3/D1.4). Kein Push/Commit.
Ruling: Backups im Hauptdatensatz als getrennte Slots atomar aktualisieren;
keine zusätzliche Datenbankmigration nötig. Nur automatischer Save rotiert
höchstens einen fälligen Slot, Reihenfolge 180 > 60 > 15.
Ruling: Web Locks ohne erzwungene Übernahme; fehlt API, kein ungeschütztes
Schreiben. CAS aus D1.1 bleibt zusätzlich bestehen.
Ruling: Startverhalten bleibt bis D1.3 unverändert. Neue Spielrunde bekommt
neue ID und überschreibt keinen älteren Stand. Laden/Weiterführen über Menü
kommt im nächsten Paket, kein ungefragtes automatisches Laden.
