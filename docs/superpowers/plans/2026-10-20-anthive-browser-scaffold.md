# Anthive Browser Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make Anthive a minimal Phaser 3, TypeScript, and Vite browser app that starts and builds without implementing game mechanics.

**Architecture:** Keep one browser app at the Anthive root. Vite serves and builds it, TypeScript checks the source, and a single Phaser scene displays a diagnostic label in a 16:9 landscape canvas. Portrait viewports show a turn-device prompt without locking device orientation. Preserve the v3 handoff as the game-design authority.

**Tech Stack:** Phaser 3, TypeScript, Vite, npm.

**Spec:** `docs/superpowers/specs/2026-10-20-anthive-browser-scaffold-design.md`

## Global Constraints

- `ANTHIVE_Gesamtdokument_Entwicklung_Codex_v3.docx` is the central project and design reference; keep its decided, provisional, and open distinctions.
- Use Phaser 3, TypeScript, and Vite for this initial browser scaffold; do not treat this as a decision about future app packaging.
- The initial screen is a diagnostic placeholder only. Do not add game mechanics, assets, game rules, balance values, persistence, or touch controls.
- Do not add an iOS wrapper or a second application target.
- Do not copy Terraria or other third-party art.
- Preserve Phaser's required MIT license notice in `THIRD_PARTY_NOTICES.md`.
- Current Vite requires Node.js 20.19+ or 22.12+; the VM has Node.js v24.22.0 and npm v11.19.1.
- Do not claim browser or iPhone testing unless performed.
- Do not modify files outside `/home/paul/Desktop/anthive`.

**Interfaces:**
- Consumes: The approved browser scaffold spec and the v3 game-design reference.
- Produces: An npm project with `dev`, `build`, and `preview` scripts; a Phaser 3 startup scene; and documented setup and preview instructions.

- [ ] **Step 1: Add the npm manifest and install dependencies**

Create `package.json` with `name: "anthive"`, `version: "0.1.0"`, `private: true`, `type: "module"`, and scripts:

- `dev`: `vite`
- `build`: `tsc --noEmit && vite build`
- `preview`: `vite preview`

Install Phaser 3 with `npm install phaser@^3`, and install Vite and TypeScript as development dependencies with `npm install --save-dev vite typescript`. Keep `package-lock.json` generated by npm.

- [ ] **Step 2: Configure Vite, TypeScript, and the page shell**

Create `vite.config.ts` using Vite's `defineConfig` with the default application behavior. Create a strict, no-emit TypeScript configuration using `module: "ESNext"`, `moduleResolution: "Bundler"`, `target: "ES2020"`, and DOM libraries. Create `index.html` with a UTF-8 declaration, responsive viewport metadata, a `#game` mount element, and `/src/main.ts` as its module entry. Create `.gitignore` entries for `node_modules/`, `dist/`, and `.DS_Store`.

- [ ] **Step 3: Implement the diagnostic Phaser scene**

In `src/game/config.ts`, configure `Phaser.AUTO`, the `#game` parent, a 640 by 360 base size, `Phaser.Scale.FIT`, and `StartupScene`. In `src/main.ts`, import the stylesheet and configuration and create one `Phaser.Game`. In `src/game/scenes/StartupScene.ts`, draw only the text `ANTHIVE prototype` centered in the canvas. Add no simulation, controls, assets, or persistence. In `src/style.css`, remove browser margins, preserve the 16:9 landscape play area, and show a turn-device prompt in portrait viewports without locking orientation.

- [ ] **Step 4: Record the Phaser notice and update README**

Copy the required MIT notice from the installed Phaser package into `THIRD_PARTY_NOTICES.md`. Update `README.md` with the required Node/npm version, `npm install`, `npm run dev`, `npm run build`, and `npm run preview`; explain the source files and placeholder-only behavior; and describe iPhone preview on the same network using `npm run dev -- --host 0.0.0.0` and the VM's reachable IP. State that iPhone access has not been tested in this VM.
